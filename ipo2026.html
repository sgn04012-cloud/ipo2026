# 2026 IPO 밸류에이션 DB — 자동화 셋업 가이드 ## 전체 구조 ``` DART API → Netlify Function → Claude API → Supabase DB → 웹 화면 ↑ cron-job.org (매월 1일·15일 자동 호출) ``` --- ## STEP 1. DART API 키 발급 (무료) 1. https://opendart.fss.or.kr 접속 2. 상단 메뉴 → 인증키 신청/관리 3. 회원가입 → 인증키 발급 신청 4. 이메일로 발급된 키 저장 (예: `a1b2c3d4e5f6...`) --- ## STEP 2. Supabase 셋업 (무료) 1. https://supabase.com → 새 프로젝트 생성 2. 좌측 SQL Editor → 새 쿼리 → `supabase-setup.sql` 전체 붙여넣기 → Run 3. Settings → API → 아래 두 가지 복사: - **Project URL**: `https://xxxxxxxx.supabase.co` - **anon key** (public): `eyJ...` (긴 문자열) - **service_role key** (비밀): Netlify Function에서 사용 --- ## STEP 3. Netlify 배포 1. https://github.com → 새 레포지토리 생성 → 이 폴더 파일 전체 업로드 2. https://netlify.com → "Import from Git" → 해당 레포 선택 3. Netlify Site → Environment Variables 에 아래 5가지 추가: | 키 이름 | 값 | |------------------------|-----------------------------| | `DART_API_KEY` | DART에서 발급받은 키 | | `ANTHROPIC_API_KEY` | Anthropic Console API 키 | | `SUPABASE_URL` | `https://xxxxxxxx.supabase.co` | | `SUPABASE_SERVICE_KEY` | Supabase service_role 키 | | `CRON_SECRET` | 아무 랜덤 문자열 (예: `abc123xyz`) | 4. Deploy → 완료 후 URL 확인 (예: `https://musical-swan-xxxxxx.netlify.app`) --- ## STEP 4. 자동 스케줄 설정 (cron-job.org, 무료) 1. https://cron-job.org 가입 2. 새 Cronjob 생성: - **URL**: `https://[내Netlify주소]/.netlify/functions/dart-update-background` - **헤더 추가**: `x-cron-token: [CRON_SECRET 값]` - **스케줄**: 매월 1일 오전 9시 (`0 9 1 * *`) 3. 두 번째 Cronjob: - 동일 URL, 헤더 - **스케줄**: 매월 15일 오전 9시 (`0 9 15 * *`) --- ## STEP 5. 웹 화면 설정 1. 배포된 `ipo2026.html` 접속 2. 우상단 **⚙ 설정** 버튼 3. Supabase URL과 anon key 입력 → 저장 4. 데이터가 없으면 Supabase에서 자동으로 불러옵니다 --- ## 자동 업데이트 동작 원리 ``` 매월 1일·15일 오전 9시 cron-job.org가 Netlify Function URL 호출 Netlify Function (dart-update-background.js): 1. DART API에서 최근 17일 증권신고서(지분증권) 목록 조회 2. 필터링: - stock_code 있음 → 이미 상장 기업 → 제외 (유상증자 등) - 기업인수목적 / 스팩 / SPAC → 제외 - 유상증자 포함 → 제외 3. [기재정정] 분리 4. 각 기업 ZIP 문서 다운로드 → 텍스트 추출 5. Claude가 공모가 산정 정보 JSON 파싱 6. Supabase에 저장 (신규 추가 / 기재정정 업데이트) → 웹 화면 새로고침 시 자동 반영 ``` --- ## 추가 참고 - DART API 문서: https://opendart.fss.or.kr/guide/main.do - Netlify Functions: https://docs.netlify.com/functions/overview/ - 에러 확인: Netlify → Functions → Logs 탭 - 수동 실행: 브라우저에서 Function URL 직접 호출 (x-cron-token 파라미터 포함) `https://[주소]/.netlify/functions/dart-update-background?token=[CRON_SECRET]`
